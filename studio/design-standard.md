# Studio design standard

Every foundation, custom build and design review reads this file. Add a rule whenever the AI does something that annoys you.

## Principles

- Restrained interfaces beat decorative ones. Typography and photography carry the identity, not effects.
- Every homepage tells one story, from the first viewport to the conversion. Each section has a reason to be where it is.
- One primary action per page. Secondary actions are visibly secondary. Never more than two competing calls to action in a viewport.
- Design mobile on purpose. Don't just stack the desktop layout. Thumb-reach CTAs, readable line lengths, no tiny tap targets.
- Animation communicates hierarchy or atmosphere. It is never there to prove JavaScript exists. Keep it short and subtle, and respect `prefers-reduced-motion`.
- Specific beats generic. Every headline should only make sense for this business.

## Avoid

- Gratuitous gradients, glows, glassmorphism, floating blobs and orbs.
- Generic SaaS aesthetics (feature-card triplets, "Elevate your…", "Unlock…", "Seamless…") on non-SaaS businesses.
- Oversized pill buttons unless the brand truly calls for them.
- Card grids as the default answer to every section. Use lists, editorial rows, numbered items and split layouts as well.
- Purple/indigo as the default accent. Rainbow icon sets. Emoji as icons.
- Stock photos of people smiling at laptops, handshakes, or anyone who could be mistaken for the owner or staff.
- Clichés: "look no further", "one-stop shop", "second to none", "your trusted partner", "we pride ourselves".
- Industry clichés named in the foundation's avoid list, such as black-and-gold limousine styling or clip-art spanners for trades.
- Centring everything. Use alignment to create hierarchy.

## Craft

- Display type does real work: a confident scale jump between display and body, tight leading on large headings, and generous measure control (55–75 characters) for body copy.
- Generous, consistent vertical rhythm. Sections breathe. Desktop section spacing is usually 96–160px.
- Small, deliberate radius (0–8px) unless the brand is soft by nature.
- Colour: mostly neutrals, with one accent used sparingly and on purpose. All text meets WCAG AA contrast.
- Photography: crop with intent, vary scale, never repeat the same photo, never stretch low-resolution images to full-bleed.
- Real details build trust: real phone number, real hours, real reviews, real suburbs.
